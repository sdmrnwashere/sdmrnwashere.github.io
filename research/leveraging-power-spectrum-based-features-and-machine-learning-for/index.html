Leveraging Power-Spectrum-Based Features and Machine Learning for Resource-Efficient Cough Classification in Respiratory Disease Monitoring

Sadman Rahman, Irtiza Mohtasim, Saquib Farhan, Kazi Newaj Faisal

publishedIEEE SPICSCON★ Best Paper Award
Read the paper ↗All research

Abstract

Cough classification is a crucial task for early diagnosis of respiratory diseases such as pneumonia and chronic obstructive pulmonary disease. This paper presents a novel approach for classifying wet and dry coughs using power spectrum features and classical machine learning models. The proposed framework extracts statistical descriptors from segmented cough signals and addresses class imbalance using the synthetic minority over-sampling technique. Four widely used classifiers—support vector machines (SVM), k-nearest neighbors, decision trees, and ensemble methods—are evaluated across different dataset configurations and segmentation schemes. Experimental results demonstrate that SVM, when combined with 16-segment features, achieves the highest classification accuracy of 93.67%. The framework is validated on a dataset of 1,908 cough recordings and offers a practical, resource-efficient solution for real-time, resource-constrained applications in early disease detection and telemedicine. The results highlight the effectiveness of statistical features over deep learning approaches, offering a balance between accuracy and computational efficiency.
